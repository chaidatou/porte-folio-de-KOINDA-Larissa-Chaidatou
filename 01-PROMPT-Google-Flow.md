# 🎬 Prompt Google Flow / Veo — Vidéo d'accueil "Cheveux → Chiffres → Câbles → Cadenas"

## La séquence voulue (l'histoire en 4 temps)
1. **Ton visage** — portrait, expression calme et confiante. Léger mouvement / rotation douce.
2. **Les cheveux se transforment en CHIFFRES** — mèches qui deviennent des flux de chiffres
   lumineux (0, 1, 2… code binaire et numérique) rose et violet.
3. **Les chiffres deviennent des CÂBLES** — les chiffres s'organisent en câbles/fils réseau
   élégants qui se connectent, se coordonnent entre eux, comme une infrastructure vivante.
4. **Les câbles forment un CADENAS** — tout converge et se verrouille en un cadenas magnifique,
   lumineux, symbole final de la cybersécurité.

---

## ÉTAPE 1 — Ta photo
- Portrait net, visage bien éclairé, de face ou léger trois-quarts.
- Fond simple et sombre de préférence.
- Bonne résolution.

## ÉTAPE 2 — LE PROMPT (à coller dans Google Flow, image-to-video)

Colle ta photo, puis ce prompt (en anglais — Veo répond mieux) :

```
Cinematic portrait of a confident young African woman, calm and powerful expression,
subtle slow head movement. 

Her hair gradually transforms into glowing streams of NUMBERS — cascading digits and
binary code (0s and 1s) in luminous pink and violet light, flowing like strands.

The numbers then reorganize into elegant, glowing NETWORK CABLES and fiber-optic wires
that connect and coordinate with each other, weaving into a living cybersecurity
infrastructure around her.

Finally, all the cables converge and lock together to form ONE magnificent, radiant
PADLOCK — a stunning symbol of cybersecurity, glowing in a pink-to-violet gradient.

Style: premium cinematic, elegant, luxurious, mysterious. Dark background (#0a0714),
soft pink (#FF2E88) and violet (#7c3aed) lighting, shallow depth of field, high-end
tech aesthetic like Apple × Interstellar. Smooth slow motion, seamless transformation,
no text, no glitch, no cyberpunk cliché. Refined and breathtaking.
```

## ÉTAPE 3 — Réglages
- **Durée** : 5–6 secondes (la transformation a besoin de temps pour respirer)
- **Format** : 16:9 pour desktop — génère aussi une version 9:16 pour mobile
- **Style** : cinematic / realistic
- Génère **plusieurs variantes** et garde la plus belle.

## ÉTAPE 4 — Export
- **MP4** haute qualité, nommé `intro-larissa.mp4`
- Capture aussi l'**image finale du cadenas** (frame figée) → `intro-poster.png`
  (sert de poster avant chargement + secours sur mobile)

---

## 🎯 Astuces pour obtenir CETTE séquence précise
Si Veo saute une étape ou va trop vite, génère la vidéo en insistant sur les mots-clés d'étape :
- Pour renforcer les chiffres : ajoute *"hair clearly turns into flowing numbers first"*
- Pour renforcer les câbles : ajoute *"numbers clearly become connecting network cables"*
- Pour renforcer le cadenas : ajoute *"cables clearly assemble into a single glowing padlock"*

Tu peux aussi générer la séquence **en 2 clips** si tout-en-un est trop instable :
- Clip A : visage → cheveux → chiffres → câbles
- Clip B : câbles → cadenas final
…puis demander à Claude Code de les enchaîner. (À ne faire que si le clip unique déçoit.)

## ⚠️ Honnêteté
Veo ne rendra peut-être pas les 4 étapes parfaitement du premier coup — c'est une séquence
ambitieuse. **Génère plusieurs fois**, ajuste, garde la meilleure. Même si une étape est plus
subtile que prévu, l'effet cheveux → code → cadenas reste spectaculaire. Vise le "assez beau
pour couper le souffle", pas la perfection au pixel.
